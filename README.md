# Trabalho — Linguagem de Programação em C

Repositório do trabalho em grupo com 20 programas do 1º semestre da disciplina **Linguagem de Programação em C**.

Autores: **Leonardo Cassiano Bruchez Pereira** e **João Vitor Gonçalves da Silva**.

Observação:

- Questões **1 a 10** foram feitas no **Visual Studio Code** (arquivos `.c`).
- Questões **11 a 20** foram feitas no **Dev-C++** (arquivos `.cpp`).
- Por isso o projeto possui **C e C++** (extensões diferentes: `.c` e `.cpp`).

---

## Como compilar e executar (Windows / PowerShell)

### Para arquivos `.c` (C)

Exemplo (Questão 1):

```powershell
gcc 1.c -o q1
.\q1.exe
```

### Para arquivos `.cpp` (C++)

Exemplo (Questão 11):

```powershell
g++ 11.cpp -o q11
.\q11.exe
```
