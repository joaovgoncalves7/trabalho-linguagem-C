# Trabalho Prático — Linguagem de Programação em C

## Sobre o Projeto

Este repositório contém a resolução das 20 questões propostas no Trabalho Prático da disciplina **Linguagem de Programação em C**, desenvolvido durante o 1º semestre do curso.

O objetivo da atividade é aplicar os principais conceitos estudados na disciplina, incluindo:

- Tipos de dados
- Expressões e operadores
- Entrada e saída de dados
- Estruturas de decisão
- Estruturas de repetição
- Vetores e matrizes

## Observação sobre os Arquivos

As questões foram desenvolvidas utilizando ambientes diferentes:

- Questões **1 a 10** desenvolvidas no **Visual Studio Code**, utilizando arquivos `.c`.
- Questões **11 a 20** desenvolvidas no **Dev-C++**, utilizando arquivos `.cpp`.

Por esse motivo, o GitHub identifica o repositório como contendo tanto **C** quanto **C++**.

## Como Compilar e Executar

### Arquivos C (.c)

Exemplo utilizando a Questão 1:

```powershell
gcc 1.c -o q1
.\q1.exe
```

### Arquivos C++ (.cpp)

Exemplo utilizando a Questão 11:

```powershell
g++ 11.cpp -o q11
.\q11.exe
```
